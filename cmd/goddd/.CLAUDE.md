# cmd/goddd 输出颜色语义

本文档定义 `cmd/goddd` 命令行工具中颜色与符号的使用规范。

## 颜色/符号含义

- 绿色 `✓`：成功。表示该子任务已完成且无异常。
- 红色 `✗`：错误。表示该子任务失败，整个流程终止。
- 黄色 `⚠`：警告。表示该子任务已完成，但存在需要用户手动处理的遗漏或可选依赖缺失，流程继续。
- 蓝色：交互式提示，用于需要用户输入的确认问题。

## 组合规则

- 同一个小任务内，绿色与红色/黄色不会同时出现。
- 可选工具（如 goimports、wire）未安装时，使用黄色 `⚠` 警告并继续。
- 可选工具已安装但执行失败时，使用红色 `✗` 并终止流程。
- 最终成功提示统一使用绿色，例如 `✓ 项目初始化成功`、`✓ 代码生成完成`。

## cobra 子命令规范

- 所有子命令必须设置 `SilenceUsage: true`，确保 Usage 仅在参数解析错误时打印，业务逻辑错误不打印 Usage。
